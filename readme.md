A simple web app that calculates Body Mass Index (BMI) from weight and height, and shows a health category with a visual indicator.
Features
Enter weight (kg) and height (cm)
Calculates BMI instantly
Shows category: Underweight / Normal / Overweight / Obese
Visual bar with a marker showing where your BMI falls
Health tip based on the result
Tech Stack
HTML5
CSS3
Vanilla JavaScript
How to Run
Download this repository
Open index.html in any browser
Enter your weight and height, click "Calculate BMI"
